
*Instalação e dependências*

Antes de executar o projeto, é necessário listar todas as dependências da linguagem Python, juntamente com suas respectivas versões, para garantir o funcionamento correto da aplicação.

*Bibliotecas utilizadas*

Algumas das bibliotecas utilizadas no projeto:

pip install torch
pip install ultralytics opencv-python numpy
pip install torch torchvision torchaudio
pip install opencv-python
pip install ultralytics

*Gerenciamento das dependências*

Para listar todas as bibliotecas instaladas e suas respectivas versões, gerando o arquivo `requirements.txt`, utilize:

pip freeze > requirements.txt

Para instalar todas as bibliotecas listadas no arquivo `requirements.txt`, utilize:

pip install -r requirements.txt
